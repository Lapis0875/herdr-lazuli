## MIT License

### cockpit

- Source: https://github.com/quaresc/cockpit, release 0.38.5, as its release archive installs it: `app/mods/cockpit/`,
  `app/layouts/cockpit.json`, `app/layouts/cockpit.svg` and the `layout:cockpit` section of `app/keys.json`.
- In this repository:
  - `mods/lstack-herdr-cockpit/`: every file except the twelve `lh-*` components, `icons/folder-plus.svg` and
    `.lstack-sync.json` is cockpit's mod, 36 files and 143 icons.
  - `layouts/lstack-herdr.json`: cockpit's layout.
  - `layouts/lstack-herdr.svg`: cockpit's `cockpit.svg`, unchanged; `preview.png` is a raster of it.
  - `keys.json`: cockpit's `layout:cockpit` key bindings.
  - `mods/lstack-herdr/hooks.mjs`: short excerpts of cockpit's code, used as anchors.
- Modified by lstack-herdr (`mods/lstack-herdr/sync.mjs` makes every change):
  - The mod-name rewrite: in every `.js` file, `mods/cockpit/` paths, `cockpit.<command>` and `cockpit.<key>` string
    literals, `mod: "cockpit"` and `.mod === "cockpit"` now name `lstack-herdr-cockpit`.
  - 17 hooks, listed in `mods/lstack-herdr/hooks.mjs`: `main.js` (2), `status.js` (4), `activity.js` (3), `fleet.js`
    (2) and `home.js` (6).
  - `mod.json`: the title is `Cockpit (lstack-herdr)`.
  - Added: the twelve `lh-*` components, `icons/folder-plus.svg` and the `.lstack-sync.json` build stamp.
  - The layout: every `mod: "cockpit"` names the fork, the side panel's `files` block shows the fork's `files` view
    instead of Herdr's `files` mod, a `tree` block is added to `panel-body`, and `preview` names
    `layouts/lstack-herdr.svg`.
  - The keys: the section is `layout:lstack-herdr`, every `cockpit.` action is renamed `lstack-herdr-cockpit.`, and
    `ctrl-cmd-6` is added.
- Each changed file says so: every cockpit `.js` file the generator changes starts with one added line, above
  cockpit's own first line:

  ```js
  // Modified by lstack-herdr (https://github.com/Lapis0875/herdr-lstack-layout): generated by mods/lstack-herdr/sync.mjs from cockpit <version>, cockpit's own mod name rewritten to lstack-herdr-cockpit[, lstack-herdr hooks applied].
  ```

  `<version>` is the cockpit version the fork was built from (0.38.5 here). The bracketed part appears only in the
  files the hooks change. In this build, 20 files carry the notice; `activity.js`, `fleet.js`, `home.js`, `main.js`
  and `status.js` carry the hooks part.

  `mod: "cockpit"` it opens panes with (and the comment showing that call) and its shared key `cockpit.code.panes` name
  `lstack-herdr-cockpit`. As section 4(b) of the Apache License 2.0 requires, the file says it was changed: its first
  line is lstack-herdr's notice (see cockpit above), without the hooks part. cockpit's header follows, and its credit
  to herdr-editor-layout (Apache-2.0, "modified for cockpit") is unchanged.

- Source: the `files` mod that ships with the Herdr app (https://herdr.dev). The app's licence is the Apache License
  2.0; it names no copyright holder and the app ships no NOTICE file, so the credit goes to the Herdr app (herdr.dev).
- In this repository: the folder tree of `mods/lstack-herdr/components/lh-files.js` (copied into the fork as
  `mods/lstack-herdr-cockpit/lh-files.js`), ported from `mods/files` as it shipped beside cockpit 0.38: folders load
  when opened, git marks, 500 entries a folder and 5 000 in all, remote spaces and Windows listed the same way.
- Modified by lstack-herdr: the tree is part of the side panel's Files tab, with an editor and file operations
  (`lh-files-ops.js`) added.
