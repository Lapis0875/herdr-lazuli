# lazuli
에이전트, PR, CI를 한 화면에 모은 Herdr 레이아웃.
cockpit 없이 혼자 동작합니다.
![lazuli 홈 화면](docs/frame.svg)
## 설치
1. `layouts/lazuli.json`을 Herdr 홈에 복사
2. 설정에서 **lazuli** 레이아웃 선택
3. `gh auth status`로 로그인 확인
