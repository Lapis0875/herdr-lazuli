## Result

- **Import and lexing:** pass. The static import of the ESM file works under `herdr-app check` and live. QuickJS supports the lookbehind and `\p{…}` regexes marked feature-tests at load. Lexing takes 1 ms, and the tree equals Node's.
- **Theme colors:** pass for both paths. TextView draws links in `accent` and text in `foreground`; the spans use the same tokens explicitly.
- **Wrapping:** pass for both paths.
- **Link click:** not run (it needs a pointer). Handlers are wired in both columns and log to `data/lz-spike/s7-clicks.json`; the header line counts clicks. Manual steps below.
- **Emphasis weight:** with Herdr's default UI font, neither path shows bold or italic. Weight works only with a family that has real bold faces installed (`Apple SD Gothic Neo` covers Latin and Hangul).

## Consequence for implementation

- **Import:** keep `import { lexer } from "./vendor/marked.esm.js"` in `core/md-tree.js`. No Node fallback is needed.
- **Inline path:** draw Markdown inline text as wrapped spans (column B). Element-level control is needed for code highlighting, images and anchors. Links get `on_click` with `theme().accent`. A soft line break inside a paragraph is a space; a `\n` left in a `whitespace_nowrap()` word made a two-line element in the first draft (`img/s7-1.png`).
- **Emphasis faces:** bold, headings and italic need font families with real faces. Ask the UI slice (U1, U5) to pick:
  - a bold-capable family per script, e.g. `Apple SD Gothic Neo` on macOS for Hangul and Latin;
  - or a size/color treatment instead of weight.

  Do not rely on `font_weight` with the default UI font.
- **Code spans:** use `raised`, not `surface`, as their background; `surface` can equal `background`.
- **Korean authoring:** document `**"인용"**이` (emphasis closed by punctuation and then a particle) as a CommonMark limit, not a lazuli bug.
- **License:** T15 takes `marked.LICENSE` from the npm package, not jsDelivr's `LICENSE.md` path (404).
