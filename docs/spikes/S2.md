# S2: terminal-notifier on macOS 27

**Verdict: Pending (manual).** Installing worked. The first post triggered macOS's permission request and blocked for more than 30 s, until the spike killed it. Permission is now `denied`, so every post exits 3 at once with "Notifications are turned off". Showing a banner and clicking it need the owner; steps below. Until they pass, A8's fallback (toast + `setBadge`) stays the default.

Run 2026-11-19 on macOS 27.0 (26A428), Herdr 0.1.16 (`dev.herdr.app`).

## Question

Does `terminal-notifier` post a banner on macOS 27, and does a click run `-execute` and activate Herdr (A8)?

## Manual steps (owner, about 3 minutes)

1. **Allow notifications for terminal-notifier.** Either:
   - System Settings → Notifications → "terminal-notifier" → turn on "Allow notifications", style Banners; or
   - `tccutil reset UserNotification fr.julienxx.oss.terminal-notifier`, then allow the prompt the next post shows.

   Check with `terminal-notifier -diagnose`: its `authorization` line should no longer read `denied` or `not requested yet`. The exact word for "allowed" was not observed.
2. Bring another app to the front (for example Finder), so Herdr is in the background.
3. In any shell, run `/tmp/lz-spike-s2/post.sh`. It records each post's exit code and duration in `/tmp/lz-spike-s2/post-results.log`, and runs `-list ALL` after posting.
4. Click banner **N1**. Herdr should come to the front, and `/tmp/lz-spike-s2/clicked.log` should get `N1 clicked <time>`.
5. Put Herdr in the background again. Click banner **N2**, or open it from Notification Center. `clicked.log` gets `N2 clicked <time>` and the output of `herdr-app do lz-spike.ping`:
   - `{"ok": true}` if an lz-spike tab was the shown tab;
   - the "unknown command" error otherwise.

   Either answer proves the click's shell can run `herdr-app`.
6. *(Optional, the real A8 action.)* Run:

   ```
   terminal-notifier -title lazuli -message focus -activate dev.herdr.app -execute "/Users/lapis0875/.local/bin/herdr-app do agent.focus --terminal <an agent address> >> /tmp/lz-spike-s2/clicked.log 2>&1"
   ```

   Click it. Expect `{"ok": true}` in `clicked.log` and that agent shown.
7. **Pass:** the banner shows, exit 0 in `post-results.log`, and N1's click both activates Herdr and appends to `clicked.log`. Record the post duration: whether a post with `-execute` returns at once or waits for the click.

## Consequence for implementation (T14, `sys/notify.js`)

- **Permission before posting:** never let the first post run under `exec`'s default 30 s timeout. Here the process was killed while macOS showed the permission prompt, and the permission ended up `denied` (steps 4–5; [INFERENCE] the kill caused it). Before using terminal-notifier, run `terminal-notifier -diagnose` and parse `authorization`:
  - **Allowed** (any value other than the two below; the exact word was not observed): use terminal-notifier.
  - **`not requested yet`:** do not post from the background. Offer a one-time "Enable system notifications" action in lazuli settings. It runs the first post without a short timeout (`exec(..., {timeout: 600000})` inside `cx.spawn`) and tells the person to click Allow.
  - **`denied`:** use the A8 fallback. Settings shows "Turn on notifications for terminal-notifier in System Settings → Notifications".
- **Exit 3:** means "notifications turned off": take the fallback (toast + `setBadge`), as §7 already says for exit ≠ 0. Cache the result so a denied state does not cost an `exec` per event.
- **Click actions:** `-execute "herdr-app do lazuli.target:<x>"` works only while a lazuli copy that handles it is shown. The `status` copy is always shown in the lazuli layout, but not after a layout switch. Keep `-activate dev.herdr.app` so the click always brings Herdr forward. For agents, prefer the built-in `agent.focus --terminal <addr>`, which needs no mod.
- **No `-sender`:** 3.1.0 removed it, so §7's choice stands.
- **Pending:** whether a successful post with `-execute` returns at once. The manual run records it. If it blocks until the click, notify must start it detached (`hc run --bg … --rm`) instead of `exec`.
