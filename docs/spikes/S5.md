## Consequence for implementation (T12, `sys/runner.js`, `bin/run-agent.mjs`)

- **Launch:** keep §4.8 as designed: `hc(["run","--bg","--json","--cwd",dir,"--label","lazuli.run=<id>","--","node",wrapper,…])` from the mod. It has no parent, is invisible, and is not capped at 600 s.
- **Stopping:**
  - `hc kill` sends **SIGHUP** to the process group, not SIGTERM. `run-agent.mjs` must treat SIGHUP like SIGTERM: forward it to its child group, then write `<id>.exit` with `signal`.
  - [INFERENCE] A program that calls `setsid` or `nohup` itself would escape the group kill.
- **Cleanup:** a finished terminal is kept until `hc rm`. The runner must `hc rm` the address after it has read `<id>.exit`. Without that, finished terminals pile up (`hc ls` reports them as `hidden_finished`).
- **Headless agents:** `omp -p` under `hc run --bg` raises no Herdr toast and is not an agent row, so headless AI features stay quiet.
- **Shell launches:** never call `hc run` from a shell inside an agent terminal without `--no-parent --no-notify`. The default parent is that terminal, and hc types notes into it. This matters for test scripts. The mod's `hc()` has no parent.
