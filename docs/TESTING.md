# lazuli live-window acceptance

Use the owner's **running Herdr window**, in a dedicated `lazuli-spike` space. Never launch a second window or use a scratch `HERDR_APP_HOME`: instances share herdr-core's document. Use only synthetic files and accounts approved for testing. Run `herdr-app check` on the installed lazuli mod, use `herdr-app status` to identify the space and focused pane, and capture each result with `herdr-app shot <evidence-name>.png`. Commands below use `herdr-app do lazuli.<command>`; keyboard shortcuts are alternatives. Record screenshots and any failure against the scenario ID.

## A3: application rows

1. **Home and shell:** Run `herdr-app do lazuli.home`. Inspect the stage board, agent/PR cards, next actions, app summaries, recent events, spend and pending restore. Check sidebar pins, badges, machines, spaces, tabs, worktrees, bell and status counts. Expected: data agrees with synthetic agent state and each section opens its destination. Evidence: `herdr-app shot a3-home.png`.
2. **Inbox:** Run `herdr-app do lazuli.go:inbox`. Open a test PR and CI failure, then inspect grouped reviews, log, failed tests, threads and files; invoke start plan. Expected: detail and action correspond to the selected PR. Evidence: `herdr-app shot a3-inbox.png`.
3. **To-do and routines:** Run `herdr-app do lazuli.go:todo`; add, edit, check, reorder, undo and delete a synthetic item and open its linked issue. Run `herdr-app do lazuli.go:routines`; create a synthetic shell routine, schedule, run and stop it, then inspect output, cost, history, settings and worktree. Expected: each change persists and history reports the outcome. Evidence: `herdr-app shot a3-todo-routines.png`.
4. **Panels and call tree:** Press Command-1 for Review; inspect uncommitted, branch and PR diff, send a line comment and request an AI walkthrough. Press Command-2 for Files; create, rename and delete a synthetic file and folder, including confirmation. Press Command-3 for shipped Changes; Command-4 for call tree, open a run and transcript. Expected: selected data and actions match the focused workspace. Evidence: `herdr-app shot a3-panels.png`.
5. **Queue, recap, restore and palette:** Press Option-Command-Q; add, edit, reorder, remove and send queued prompts to a synthetic agent. Press Command-R to inspect stages, answer, recap, snooze, fork and weekly time. Create a pending restore and press Option-Command-R. Press Shift-Command-P and search commands, keys, layouts, spaces, tabs, agents, PRs, to-dos, routines and sessions. Expected: each action targets the selected agent and restore retries pending terminals. Evidence: `herdr-app shot a3-queue-recap.png`.
6. **Restore after a tool switch:** In a recovered terminal (pending restore of an omp session), start a different agent (e.g. claude) before sending it a first message, restart Herdr, and check the old conversation is not restored into that terminal; repeat with the same tool on its old session and check it is acknowledged (no second restore). Expected: a restore never attaches one tool's conversation to another tool's shell. Evidence: `herdr-app shot a7-tool-switch.png`.

## B1–B11: files

1. **B1–B3, B11 placement and modes:** Open Files with Command-2; single-click a synthetic Markdown file, click another, double-click it and reopen it. Press Shift-Command-O to find a file, then Shift-Command-V repeatedly. Repeat with HTML, PDF, SVG, PNG/JPEG/GIF/WebP, text and a binary file. Expected: center preview reused once per space, double-click pins, duplicates focus existing tab, dirty marker appears; modes/defaults follow DESIGN B3, binary shows info. Evidence: `herdr-app shot b1-b3-b11.png`.
2. **B4–B5 edits and drafts:** Edit a text file, change it externally and save; choose reload, repeat and choose overwrite. With no edits change it externally. Test a file over 400,000 characters, a NUL file and a non-writable file. Dirty another file, wait one second, reopen, restore draft; repeat and discard. Expected: conflict choice, clean auto-reload, correct read-only limits, recovery banner and draft removal after save/discard. Evidence: `herdr-app shot b4-b5.png`.
3. **B6 Markdown:** Edit a Markdown file containing headings, lists, table, quote, code and local image. Expected: native preview tracks unsaved typing; Chrome view shows only saved content, including Mermaid and math. Evidence: `herdr-app shot b6-markdown.png`.
4. **B7–B8 HTML:** Open synthetic HTML with a module script, fetch, internal anchor and external link. Cycle Edit/Split/Preview, type and click, save while scrolled; open a second HTML tab, then close both. Expected: local scripts and interaction work, reload preserves scroll, external link opens browser, one shared Chrome exits after five minutes. Without Chrome, expected static fallback with open-in-browser. Evidence: `herdr-app shot b7-b8-html.png`.
5. **B9–B10 PDF and remote:** Open a multi-page synthetic PDF, jump pages, toggle outline, search next/previous, follow internal/external links, copy page text and exercise fit/50/75/100/125/150/200% zoom. Check fallback when renderer build fails and pdftocairo is unavailable. Open Markdown, text, HTML and PDF from a remote space. Expected: PDF navigation/search and defined fallbacks work; remote text/Markdown are read-only and remote HTML/PDF preview unavailable. Evidence: `herdr-app shot b9-b10-pdf-remote.png`.
